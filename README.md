# AutoMind

AutoMind is a vehicle intelligence platform designed to connect
vehicle telemetry with mobile, web and intelligent services.

## Architecture

AutoMind uses:

- Microservices
- Clean Architecture
- Hexagonal Architecture
- SOLID
- Domain-Driven Design where appropriate
- API-first development
- Automated testing
- Observability
- Resilience

## Applications

### Backend

Java + Spring Boot microservices.

### Mobile

React Native.

### Web

Angular.
